# VOID Browser website

This folder contains the static landing page. The download links open the `v0.7.1` release, and the feature request form opens a prefilled issue on `SL0TH-releases/VOID-Browser`.

## Publish with GitHub Pages

1. Clone `https://github.com/SL0TH-releases/VOID-Browser` with GitHub Desktop.
2. Put this whole `docs` folder in the top level of the cloned repository. Keep `index.html`, `void.png`, and this README together inside `docs`.
3. In GitHub Desktop, commit the changes and click **Push origin**.
4. On GitHub, open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**. Select the `main` branch and `/docs` folder, then click **Save**.
6. GitHub will show the live website address on the Pages settings screen after it publishes.

The repository's Issues feature must be enabled for visitors to submit feature requests. Anyone can view a published GitHub Pages site, so only publish content you intend to make public.
